# 教学质量专项督导领域指南

## 业务问题

教学质量检查常依赖零散听课和主观印象，无法把课堂观察、作业、测评、家长反馈与整改闭环连接起来。

## 产品解决方案

围绕一个学科或校区的质量主题，组织证据采样、诊断、问题排序、改进实验和复测。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `supervision_scope` | 督导范围 | 是 | 学科、年级、课程或校区 |
| `quality_goals` | 质量目标 | 是 | 本次督导要回答的问题 |
| `evidence_sources` | 证据来源 | 是 | 课堂、作业、测评、家长反馈等 |
| `sample_records` | 样本记录 | 是 | 脱敏后的抽样信息 |
| `previous_actions` | 上一轮整改 | 否 | 已采取措施和结果 |
| `reviewer_roles` | 复核角色 | 是 | 教学负责人、教研组长等 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

教学负责人/教研组长应确认：质量诊断、改进实验与教师管理决定；不得替代人事处分。未经确认的内容只能作为草案。

## 主要风险

不能把有限样本当全体结论；不得用于简单教师排名；需要学科专家和课堂现场核验。
